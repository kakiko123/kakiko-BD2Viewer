# kakiko-BD2Viewer

一个**本地**的 Spine（俗称 L2D）动画查看器。它扫描你硬盘 / 手机上的 Spine 资产目录，
把 `.atlas` + `.json/.skel` + 贴图识别成一套套可播放的资产，然后播放、切动画、切皮肤、
显隐图层、截图和导出。

同一份前端代码，两种运行方式：

| 形态 | 跑在哪 | 数据从哪来 |
|---|---|---|
| **桌面版** | 本机 Node 服务（只监听 `127.0.0.1`），浏览器打开 | 读你配置里声明的目录 |
| **Android APK** | 手写的 WebView 壳（无框架） | 读手机存储 / 你授权的目录 |

> **它不含任何游戏素材。** 仓库里没有角色图、骨骼、语音，一个都没有 ——
> 它只读取你机器上已有的文件。也请不要把含素材的截图贴到仓库 / issue / 讨论区。

> **本项目基于 [Jelosus2/BD2-L2D-Viewer](https://github.com/Jelosus2/BD2-L2D-Viewer) 构建。**
> 功能形态、交互设计与资产的组织方式都来自该项目（MIT License，Copyright (c) 2025 Jelosus2）。
> 代码是**独立重写**的 —— 上游是 Vue 3 + TypeScript + Vite，本项目是原生 JS + 手写的 WebView 壳，
> **没有复制它的源码**；在此基础上把数据源换成了扫描本地目录，并加上了桌面 Node 宿主与 Android 套壳。
> 详见 [§6.1 上游项目与致谢](#61-上游项目与致谢) 与 [`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md)。

## 1. 快速开始

### 1.1 桌面版（最快能跑起来的路径）

需要 **Node.js 18+**（[下载](https://nodejs.org/)），不需要装任何 npm 包。

```bash
git clone https://github.com/kakiko123/BD2Viewer.git
cd BD2Viewer/bd2-local-viewer

cp viewer.config.example.json viewer.config.json    # ① 复制配置模板
#   然后用编辑器打开它，把 roots[0].path 改成你自己的资产目录

node server.mjs --open                              # ② 启动并打开浏览器
```

Windows 上也可以直接双击 **`bd2-local-viewer/start.bat`**（会自动找 Node）。

配置项的含义、多目录怎么加，见 [`docs/TECHNICAL.md` §5](docs/TECHNICAL.md#5-桌面版配置文件)。

### 1.2 手机端（APK）：装完还得做两件事，否则用不了

Android 11+ 的分区存储限制下，**App 没法自己在手机存储根目录建文件夹**（系统会静默拒绝），
也没法直接读别人的目录。所以这两件事必须由你来做：

| # | 做什么 | 不做会怎样 |
|---|---|---|
| ① **建文件夹** | 用任意文件管理器，在手机存储里建一个目录（比如「内部存储」根目录下的 `BD2Viewer`，或者你已经在用的模组目录如 `.BD2_Mods`），把资产按「**一个子文件夹 = 一套资产**」放进去 | App 建不出来，只能退回自己的专属目录（卸载即删、文件管理器进不去） |
| ② **给权限** | `设置 → 应用 → kakiko-BD2Viewer → 权限 → 所有文件访问权限 → 允许`。这是**特殊权限**，系统不允许 App 弹窗申请 —— App 里的「打开权限设置」按钮会直接把你送到那一页 | 读不到外部目录，只能逐个用「添加目录」走系统文件夹选择器授权，很别扭 |

做完这两步，回到 App 点「重新扫描」就能看到资产了。

> 如果你的资产是给 [BDroid_X](https://github.com/Ark-Repoleved/BDroid_X) 准备的模组源目录
> （比如内部存储下的 `.BD2_Mods`），直接把它整个加进来就行 ——
> 里面「一个子文件夹 = 一套模组」的结构正好是本项目的识别方式。
> 两者是**独立的工具**，本项目与 BDroid_X 无隶属关系、未获其背书，也不参与任何注入 / 打包行为。

## 2. 怎么用

### 2.1 桌面版

1. 左栏是资产列表（按目录分组），右边是平铺卡片墙。缩略图是**后台逐个生成**的，
   首次进一个大目录会一张张冒出来，属正常现象（生成过的会缓存）。
2. 点任意一张卡片进入播放页：左侧是动画列表 / 皮肤 / 图层，底部是播放控制与速度，
   右侧是截图与导出。
3. 要批量删：在卡片墙或列表里**长按（或右键）**进入多选 → 勾选 → 删除。
   删的是**磁盘上的真文件**，确认框会列出将被删掉的完整文件清单。

**键盘快捷键**（与 App 内帮助一致）：

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| 拖拽 / 滚轮 | 平移 / 缩放视图 | `L` | 切换图层选择模式 |
| 空格 | 播放 / 暂停 | 点击模型 | 图层选择模式下选中该图层 |
| ← / → | 后退 / 前进一帧 | `H` | 隐藏选中的图层 |
| `R` | 重置视图 | `U` | 恢复上一次隐藏 |
| `F` | 适配窗口 | `Esc` | 还原全部隐藏 |
| `[` / `]` | 上一套 / 下一套动画 | ↑ / ↓ | 上一个 / 下一个动画 |

**深链**：`http://127.0.0.1:8137/?item=<relAtlas>` 可以直接打开某一套资产。

### 2.2 Android

先确认 [§1.2](#12-手机端apk装完还得做两件事否则用不了) 那两步做完了。

1. **放资产**：把套件拷进你的目录（每个子文件夹放一套），或者在 App 里点「导入文件」直接选文件拷进去。
2. **加目录**（可选）：资产不在默认目录时，点「添加目录」用系统文件夹选择器选中它。
3. **重新扫描**：顶部状态条会显示当前用的是哪个目录；拿不到外部目录时它会**明确写出原因**，
   这时点「打开权限设置」去开权限。
4. 剩下的交互和桌面版一致。差别在：
   - **返回键**按层级退出：确认框 → 各弹窗 → 全屏侧栏 → 底部抽屉 → 批量选择 → 全屏 → 播放页 → 才退 App。
   - **全屏时音量键**切上一个 / 下一个动画（方向可在设置里改）。
   - 底部 ◀◀ / ▶▶ 切**资产**，画面两侧箭头切**动画**。
5. 导出 / 截图落在 `Downloads/BD2Viewer/`。

**扫不到东西时**，按顺序看这三条：

| 现象 | 原因 |
|---|---|
| 顶部写着「系统拒绝了在手机存储根目录建文件夹」 | 缺「所有文件访问权限」，或那个目录确实还没建 |
| 目录里有文件但列表为空 | 文件没按「一个子文件夹 = 一套」放，或缺少 `.atlas` / 骨架文件（列表会标出来） |
| 只能看到 App 专属目录 | 权限没开。要么去开权限，要么用「添加目录」授权你那个文件夹 |

### 2.3 两条容易踩的行为约定

- **按名称 / 日期排序时，卡片拖不动**（手柄「⠿」也会隐藏）。
  想拖动自定义顺序，先点回「手动」。这比「一拖就偷偷把手动顺序固化下来」好懂。
- **搜索不只看名字**：输入 `.atlas` / `.png` / `.skel` 的真实文件名，
  能反查它属于哪套资产。命中时卡片上会多一行 `🔍 <文件名>`，说明**为什么**它被搜出来。

## 4. 路线图

接下来的方向是两条主线：

**① 把 UI 设计往 BD2 原生质感上靠**

现在的界面是通用工具的样子 —— 中性灰底、系统控件、能看清就行。
下一步是让它看起来更像游戏里的东西：配色、字体、圆角、按钮与弹窗的视觉语言
向 BD2 客户端本身靠拢，卡片墙和播放页的控制条一并重做。
功能不动，先把「一眼认出这是 BD2 的工具」这件事做到。

**② 支持更多游戏文件的预览**

现在只认 Spine 一套（`.atlas` + 骨架 + 贴图）。
BD2 的模组目录里还有别的能被直接看的东西，目标是逐步把它们也纳进来 ——
在同一个目录树里点开就能预览，不必再换工具。
具体支持哪些格式会按「能不能在本地离线渲染」来挑，边做边定。

这两条之外还有一些不急的：造一套合成的测试资产让测试可移植、按目录批量导出等。
已知而未处理的问题记在 [`docs/KNOWN-ISSUES.md`](docs/KNOWN-ISSUES.md)。

## 5. 功能一览

**浏览** — 左侧资产列表（按目录分组）+ 平铺卡片墙（带缩略图）；
搜索过滤（目录名 / 文件名 / **资产内部资源文件名**）、只显示可播放的、
按 手动顺序 / 名称 / 日期 排序；**手动顺序下**卡片可拖动排序。

**语言** — 中文 / English 全量切换，首次启动询问一次，之后在「设置 → 语言」里改。

**播放** — 动画列表 / 皮肤下拉 / 图层列表（可显隐、可点选模型上的图层）/
播放暂停与速度 / 相机缩放平移 / 重置视图 / 背景色 / 每帧步进。

**输出** — 2K 截图（PNG，可带透明通道）/ 导出帧序列 ZIP / 导出 WebM 视频；
截图与导出可选「用当前镜头」和「截边长上限」。

**管理** — 长按（或右键）进入多选，批量删除整**套**资产（atlas + 骨架 + 贴图一起删），
删完顺手清空目录。桌面版删的是真文件，有二次确认。

**全屏 / 手机外壳** — 全屏模式：顶栏 ◀▶ 切资产、底栏 ◀▶ 切动画、音量键切动画、保持屏幕常亮；
手机上有底部标签栏与底部抽屉；返回键按「当前压着哪一层」逐层退出。

> **本仓库不附带任何截图。** 截图必然要用到真实的 L2D 资产，而那些资产是**需要付费获得**的，
> 其中一部分内容也不适合公开传播。所以一张都不放。
> 想看实际界面，按 [§1 快速开始](#1-快速开始) 自己跑起来最快；
> `node bd2-local-viewer/_test/shot_native.mjs` 也可以对你**本机**的资产生成一组界面图。
